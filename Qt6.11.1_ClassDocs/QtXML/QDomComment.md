# QDomComment
> Qt 6.11.1 · Qt XML · 来自 `QDomComment`

## 1. 先建立直觉

`QDomComment` 表示 XML 注释节点：`<!-- comment -->`。它用于保留文档中的说明文字、生成器标记或人工编辑提示，不参与元素文本语义。

## 2. 类说明

保留类说明：这些 API 来自 `QDomComment`，属于 Qt XML 模块，用于表示 XML 注释节点。

它继承 `QDomCharacterData`，注释正文通过 `data()`/`setData()` 操作。创建含内容的注释应使用 `QDomDocument::createComment()`。

## 3. API 速查

| API | 用来做什么 |
| --- | --- |
| `QDomComment()` | 创建空注释句柄。 |
| `nodeType()` | 返回 `CommentNode`。 |
| 继承的 `data()` / `setData()` | 读取或设置注释正文。 |

## 4. 典型流程

```cpp
root.appendChild(doc.createComment("generated by import tool"));
```

## 5. 使用场景

| 场景 | 用法 |
| --- | --- |
| 保留人工备注 | 解析后修改文档时不丢注释。 |
| 输出生成器信息 | 写入工具版本、生成时间。 |
| 清理 XML | 遍历并删除 `CommentNode`。 |

## 6. 常见坑与经验

注释内容不能包含非法注释序列，例如 `--` 在 XML 注释中有约束。拼接用户输入做注释前要清理。

不要把业务数据藏在注释里。XML 消费者可能合法忽略或删除注释。
