# QBarSeries
> Qt 6.11.1 · Qt Charts · 来自 `QBarSeries`

## 作用定位
`QBarSeries` 将同一类别下多个 `QBarSet` 并排显示，强调维度之间的绝对值比较。

## API 速查
| API | 是做什么的 |
|---|---|
| `append(QBarSet *)` | 添加一个并排比较维度。|
| `barSets()` | 取得各维度数据集。|
| `setLabelsVisible()` | 显示柱体数值。|
| `type()` | 返回普通柱状类型。|

## 使用场景
按月份比较多个产品、按地区比较多个部门的销售额。

## 常见坑与经验
- 并排维度超过三到五个后认知负担很高，宜拆图或使用交互筛选。
- 不同量纲不能放在同一柱组中比较。

## 知识点覆盖
分组柱图、绝对比较、数据维度、类别轴、可读性。
