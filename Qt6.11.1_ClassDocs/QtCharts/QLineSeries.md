# QLineSeries
> Qt 6.11.1 · Qt Charts · 来自 `QLineSeries`

## 作用定位
`QLineSeries` 将 `QXYSeries` 的相邻数据点直线连接，是趋势、时序和连续测量曲线的默认选择。

## API 速查
| API | 是做什么的 |
|---|---|
| `append()` / `replace()` | 继承自 `QXYSeries`，写入曲线点。|
| `setPen()` | 设置线宽、颜色、虚线样式。|
| `setPointsVisible()` | 同时显示采样点标记。|
| `type()` | 返回 Line 类型标识。|

## 使用场景
传感器趋势、吞吐量、响应时间、累计指标。数值波动应保留原始采样间隔，避免用等距索引伪装为时间轴。

## 常见坑与经验
- 点很多时同时开启点标记会显著增加绘制量。
- 断线需要把缺失段拆为多个系列或预处理数据；NaN 不应被当作通用断线语义。

## 知识点覆盖
折线趋势、时序、画笔样式、缺失数据、采样密度。
