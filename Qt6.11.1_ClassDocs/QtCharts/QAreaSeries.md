# QAreaSeries
> Qt 6.11.1 · Qt Charts · 来自 `QAreaSeries`

## 作用定位
`QAreaSeries` 用上边界和下边界两条 XY 序列围出填充区域。只给上边界时，默认下边界为零线。

## API 速查
| API | 是做什么的 |
|---|---|
| 构造函数 `(upper, lower)` | 指定上、下边界曲线。|
| `upperSeries()` / `lowerSeries()` | 取得边界序列。|
| `setBrush()` | 设置填充区域画刷。|
| `setPen()` | 设置边界线画笔。|
| `setPointLabelsVisible()` | 控制边界点标签。|

## 使用场景
置信区间、上下限带、范围预测、累计面积。上、下边界必须按相同 X 采样对齐。

## 常见坑与经验
- 两条边界交叉会形成复杂填充形状，先校验业务上是否允许。
- 半透明面积大量重叠时难以阅读，必要时只突出当前选中区间。

## 知识点覆盖
面积图、置信带、边界对齐、透明填充、范围数据。
