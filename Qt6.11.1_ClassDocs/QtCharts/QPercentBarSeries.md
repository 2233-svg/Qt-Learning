# QPercentBarSeries
> Qt 6.11.1 · Qt Charts · 来自 `QPercentBarSeries`

## 作用定位
`QPercentBarSeries` 将每个类别的各 `QBarSet` 归一化为 100%，专门比较构成比例而非绝对量。

## API 速查
| API | 是做什么的 |
|---|---|
| `append()` | 添加一个比例组成层。|
| `setLabelsFormat()` | 将标签格式化为百分值。|
| `type()` | 返回百分比柱状类型。|

## 使用场景
不同月份渠道占比、不同团队工作类型占比，即使各类别总量差异很大也能比较结构。

## 常见坑与经验
- 总量信息被归一化抹去；需要同时看规模时另配总量图或标签。
- 零总和类别无法可靠归一化，数据入口要明确处理。

## 知识点覆盖
归一化、百分比、组成比较、零分母、总量与比例区分。
