# QSplineSeries
> Qt 6.11.1 · Qt Charts · 来自 `QSplineSeries`

## 作用定位
`QSplineSeries` 使用平滑曲线连接 XY 点，适合连续信号的展示性插值。

## API 速查
| API | 是做什么的 |
|---|---|
| `append()` / `replace()` | 继承点数据 API。|
| `setPen()` | 设置平滑线的外观。|
| `type()` | 返回 Spline 类型标识。|

## 使用场景
温和变化的指标、演示曲线、估计趋势。用它表达“视觉平滑”，而不是声称原始数据在点间真实遵循该曲线。

## 常见坑与经验
- 高曲率或稀疏点可能出现过冲，造成曲线越过真实最小/最大值。
- 财务阶梯、离散计数、突变状态不应使用样条。

## 知识点覆盖
插值、平滑曲线、过冲、数据忠实性、可视化选择。
