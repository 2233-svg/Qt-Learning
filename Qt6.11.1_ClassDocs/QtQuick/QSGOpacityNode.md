# QSGOpacityNode
> Qt 6.11.1 · Qt Quick · 来自 `QSGOpacityNode`

## 作用定位
`QSGOpacityNode` 为子树统一乘以透明度，避免给每个材质单独传 alpha。

## API 速查
| API | 是做什么的 |
|---|---|
| `setOpacity()` | 设置 0 到 1 的子树不透明度。|
| `opacity()` | 读取当前值。|

## 使用场景
给自定义项实现整体淡入淡出，或将多个节点作为一个视觉单元统一调暗。

## 常见坑与经验
- 透明内容通常破坏不透明批处理并对顺序敏感；大量半透明叠加会带来 fill-rate 成本。
- 透明度为 0 不等于停止更新或输入；业务上隐藏时仍需另行处理。

## 知识点覆盖
Alpha 合成、子树状态、透明排序、GPU 填充率。
