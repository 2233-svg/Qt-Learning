# QSGTransformNode
> Qt 6.11.1 · Qt Quick · 来自 `QSGTransformNode`

## 作用定位
`QSGTransformNode` 为整棵子树附加 4x4 变换矩阵，适合平移、缩放、旋转或相机变换，而无需逐个改写子节点顶点。

## API 速查
| API | 是做什么的 |
|---|---|
| `setMatrix()` | 设置本节点到父坐标系的矩阵。|
| `matrix()` | 读取当前矩阵。|

## 使用场景
自定义图表缩放、地图平移或把多个图元作为一个整体旋转时，在共同父节点上设置矩阵。

## 常见坑与经验
- 矩阵乘法顺序会改变“先旋转还是先平移”；先在纸上明确坐标约定。
- 变换不改变 `QQuickItem` 的输入命中逻辑，视觉和交互若都要变，应在 item 层同步设计。

## 知识点覆盖
齐次坐标、局部变换、子树复用、视觉与命中测试分离。
