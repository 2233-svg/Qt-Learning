# QPlaybackOptions
> Qt 6.11.1 · Qt Multimedia · 来自 `QPlaybackOptions`

## 作用定位

`QPlaybackOptions` 是 `QMediaPlayer` 的播放后端配置集合，用来表达一些影响解码、硬件加速、低延迟或协议行为的选项。它让播放策略与播放器控制 API 分开，便于在设置媒体前统一配置。

## 类说明

- 头文件：`#include <QPlaybackOptions>`
- CMake：链接 `Qt6::Multimedia`
- 继承：无公开 QObject 继承，值类型

## API 速查

| API | 说明 |
| --- | --- |
| 构造/复制/赋值 | 保存一组播放配置。 |
| `reset()` | 恢复默认选项。 |
| 具体选项访问器 | 根据 Qt 版本和后端提供硬件解码、低延迟等播放策略设置。 |

## 使用场景

| 场景 | 说明 |
| --- | --- |
| 低延迟播放 | 对直播、监控、交互视频更关注延迟。 |
| 硬件/软件解码选择 | 遇到驱动问题或性能问题时调整策略。 |
| 统一播放器配置 | 在 `setSource()` 前配置播放器行为。 |

## 常见坑与经验

- 播放选项通常要在加载媒体前设置，加载后未必对当前媒体生效。
- 后端不一定支持每个选项，设置成功不代表平台会完全按预期执行。
- 调优时要结合 `mediaStatus()`、CPU/GPU 占用、实际延迟测试，不要只看 API 名称。
