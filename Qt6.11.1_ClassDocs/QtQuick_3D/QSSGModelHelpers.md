# QSSGModelHelpers
> Qt 6.11.1 · Qt Quick 3D · 来自 `QSSGModelHelpers`

## 1. 先建立直觉

`QSSGModelHelpers` 是模型相关的静态辅助函数集合。它面向渲染扩展和内部渲染代码，帮助查询模型 bounds、变换或渲染所需的模型信息。

## 2. 类说明

保留类说明：这些 API 来自 `QSSGModelHelpers`，属于 Qt Quick 3D 模块，用于辅助访问 Quick 3D 模型渲染数据。

## 3. API 速查

| API | 用来做什么 |
| --- | --- |
| 模型 bounds 查询 | 取得模型包围信息，服务裁剪、调试和辅助渲染。 |
| 模型变换/渲染信息查询 | 在扩展中读取当前帧模型状态。 |

## 4. 使用场景

| 场景 | 说明 |
| --- | --- |
| 渲染调试工具 | 画模型 bounds、法线或选择框。 |
| 自定义 pass | 按模型信息组织额外绘制。 |
| 分析场景内容 | 在 frame data 里理解可见模型。 |

## 5. 常见坑与经验

helper 返回的是渲染侧数据，和 QML 对象属性不一定处于同一同步时刻。扩展里应按当前帧数据为准。

内部 helper API 的适用面比高层 QML API 窄，跨 Qt 版本升级时要复查行为。

## 6. 知识点覆盖

- 模型渲染数据访问。
- bounds、变换和调试绘制。
- QML 属性与渲染帧状态的同步差异。
