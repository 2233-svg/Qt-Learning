# QMultiHash::iterator
> Qt 6.11.1 · Qt Core · 来自 `QMultiHash::iterator`

## 作用定位
`QMultiHash::iterator` 是可写多值哈希迭代器，可遍历每一条键值关联并修改当前值。

## API 速查
| API | 是做什么的 |
|---|---|
| `key()` | 读取当前键。|
| `value()` | 读取或修改当前值。|
| `operator++()` | 移到下一条关联。|
| `erase()` | 删除当前位置并取得后继迭代器。|

## 使用场景
遍历标签索引时更新关联对象状态，或清除符合条件的一批键值关系。

## 常见坑与经验
- 不要通过 iterator 修改键，键决定哈希位置。
- `erase()` 后必须使用返回的后继迭代器继续；其他结构修改也可能使其失效。

## 知识点覆盖
多值哈希、可写迭代、遍历删除、键不变量、迭代器失效。
