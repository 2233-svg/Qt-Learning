# QChildEvent
> Qt 6.11.1 · Qt Core · 来自 `QChildEvent`

## 作用定位
`QChildEvent` 是 QObject 父对象在子对象被添加、移除或进入析构阶段时收到的事件。

## API 速查
| API | 是做什么的 |
|---|---|
| `added()` | 判断是否为子对象加入事件。|
| `removed()` | 判断是否为子对象移除事件。|
| `polished()` | 判断子对象完成构造后通知。|
| `child()` | 取得相关子对象指针。|

## 使用场景
容器类需要自动观察或配置动态加入的 QObject 子对象时，重实现 `childEvent()`。

## 常见坑与经验
- `ChildAdded` 到达时，子类构造可能尚未结束；不要调用依赖派生类完整状态的接口。
- 子对象析构期间也可能出现事件，不能假设 `child()` 还能长期使用。

## 知识点覆盖
