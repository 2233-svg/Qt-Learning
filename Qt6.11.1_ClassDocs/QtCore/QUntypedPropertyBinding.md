# QUntypedPropertyBinding
> Qt 6.11.1 · Qt Core · 来自 `QUntypedPropertyBinding`
## 作用定位
`QUntypedPropertyBinding` 保存一个不暴露值类型的属性绑定表达式，用于在元对象和泛型属性工具中搬运绑定。
## API 速查
| API | 是做什么的 |
|---|---|
| `isNull()` | 判断是否没有绑定表达式。 |
| `valueMetaType()` | 查询绑定产出值类型。 |
| `error()` | 查询绑定求值错误。 |
| 拷贝/移动 | 在属性工具间传递绑定句柄。 |
## 使用场景
属性面板复制某个对象的绑定并安装到另一个兼容属性上。
## 常见坑与经验
- 安装前确认目标属性元类型兼容。
- 绑定表达式捕获对象的生命周期仍必须安全。
- 求值错误要记录，特别是循环绑定。
## 知识点覆盖
无类型绑定、元类型兼容、绑定错误、生命周期、反射工具。
