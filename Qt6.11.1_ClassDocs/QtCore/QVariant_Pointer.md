# QVariant::Pointer
> Qt 6.11.1 · Qt Core · 来自 `QVariant::Pointer`
## 作用定位
`QVariant::Pointer` 是 `QVariant` 的可写指针代理类型，用于泛型访问器表达“当前位置可被改写”。
## API 速查
| API | 是做什么的 |
|---|---|
| 解引用 | 访问目标 QVariant 位置。 |
| 赋值 | 修改目标位置的值。 |
| 比较 | 判断是否指向同一位置。 |
## 使用场景
可写迭代或代理接口内部使用，普通业务代码通常直接操作 `QVariant`。
## 常见坑与经验
- 不要跨越源容器修改、detach 或销毁后继续用。
- 写入前要确认目标期望类型和转换策略。
