# QBEInteger
> Qt 6.11.1 · Qt Core · 来自 `QBEInteger`

## 作用定位
`QBEInteger<T>` 将整数以大端字节序存储，便于二进制协议和磁盘格式直接表达网络序字段。

## API 速查
| API | 是做什么的 |
|---|---|
| 构造/赋值 | 从本机整数写入大端表示。|
| 转换运算符 | 读取为本机字节序整数。|
| `qToBigEndian()` | 批量转换原始数据。|

## 使用场景
定义固定二进制包头、文件格式字段或网络协议结构。

## 常见坑与经验
- 只解决字节序，不解决结构体填充、对齐和版本兼容；网络包不要直接 `reinterpret_cast` 整个 C++ struct。

## 知识点覆盖
大端序、网络序、二进制协议、对齐、跨平台格式。
