# QEventLoop
> Qt 6.11.1 · Qt Core · 来自 `QEventLoop`

## 作用定位
`QEventLoop` 是可嵌套运行的事件循环对象。它可临时等待异步结果，同时继续分发选定事件；这项能力强大但很容易制造重入。

## API 速查
| API | 是做什么的 |
|---|---|
| `exec()` | 进入局部事件循环并返回退出码。|
| `exit()` / `quit()` | 退出该事件循环。|
| `processEvents()` | 处理一批待处理事件。|
| `isRunning()` | 查询当前是否在运行。|
| `wakeUp()` | 唤醒等待中的循环。|

## 使用场景
极少数必须在同步 API 外观下等待异步任务的适配层，且已严格控制对象状态与可重入路径时使用。

## 常见坑与经验
- 嵌套 `exec()` 会让定时器、用户输入和其他信号在当前调用栈未返回时继续执行，常导致状态机错乱。
- 不要把它用作 GUI “不冻结”的通用补丁；应把 API 设计为异步信号/回调/协程风格。
- 退出条件必须连接到可靠的完成、取消与超时路径，否则可能无限等待。

## 知识点覆盖
嵌套事件循环、重入、异步适配、取消、超时、事件分发。
