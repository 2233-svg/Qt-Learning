# QCache
> Qt 6.11.1 · Qt Core · 来自 `QCache`

## 作用定位
`QCache<Key, T>` 是拥有对象的成本型 LRU 缓存，达到最大成本时会自动删除较久未使用项。

## API 速查
| API | 是做什么的 |
|---|---|
| `insert(key, object, cost)` | 插入并转移对象所有权。|
| `object(key)` | 查找并更新 LRU 使用顺序。|
| `take(key)` | 移出对象并把所有权交还。|
| `remove()` / `clear()` | 删除一个或全部对象。|
| `setMaxCost()` | 设置成本容量。|
| `totalCost()` | 查询当前成本。|

## 使用场景
图像缩略图、解析结果或昂贵对象的内存缓存。

## 常见坑与经验
- cache 拥有插入的指针，插入后不要在外部 delete。
- 成本单位由应用定义，不必是字节，但必须与对象大小大致成比例。

## 知识点覆盖
LRU、对象所有权、缓存成本、淘汰、内存管理。
