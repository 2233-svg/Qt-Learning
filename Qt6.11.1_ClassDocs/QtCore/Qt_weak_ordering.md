# Qt::weak_ordering
> Qt 6.11.1 · Qt Core · 来自 `Qt::weak_ordering`
## 作用定位
`Qt::weak_ordering` 表示弱序三路比较：可以区分小于、大于和等价，但等价值不要求完全相同。
## API 速查
| API | 是做什么的 |
|---|---|
| `less/equivalent/greater` | 三种弱序结果。 |
| 与 0 比较 | 支持 `< 0`、`> 0`、`== 0` 风格判断。 |
| 转换到 partial ordering | 在更宽松语境下使用。 |
## 使用场景
大小写不敏感字符串排序中，`"abc"` 与 `"ABC"` 可等价但对象内容不同。
## 常见坑与经验
- 等价不等于 `operator==` 一定为真。
- 用于排序时仍必须满足传递性。
## 知识点覆盖
三路比较、弱序、等价类、大小写排序、C++20 兼容。
