# QVariantPointer
> Qt 6.11.1 · Qt Core · 来自 `QVariantPointer`
## 作用定位
`QVariantPointer` 是 QVariant 相关可写指针代理，用于迭代或引用语义下修改变体值。
## API 速查
| API | 是做什么的 |
|---|---|
| 解引用访问 | 取得可写 QVariant 位置。 |
| 赋值 | 修改代理指向的值。 |
| 比较/移动 | 配合迭代器位置使用。 |
## 使用场景
Qt 容器或模型辅助接口需要把某个 QVariant 位置暴露为可写句柄。
## 常见坑与经验
- 不拥有数据，不能跨容器修改或析构长期保存。
- 写入仍要尊重目标位置期望类型。
