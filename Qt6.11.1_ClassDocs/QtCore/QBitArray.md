# QBitArray
> Qt 6.11.1 · Qt Core · 来自 `QBitArray`

## 作用定位
`QBitArray` 以位而非字节存储布尔集合，适合选择标记、位图掩码和大量开关。

## API 速查
| API | 是做什么的 |
|---|---|
| `resize()` | 调整位数。|
| `setBit()` / `clearBit()` | 设置或清除一位。|
| `toggleBit()` | 翻转一位。|
| `testBit()` | 读取一位。|
| `fill()` | 用同一值填充范围。|
| `count()` | 统计真位数量。|

## 使用场景
百万级项目的选择状态、权限位、稀疏筛选预计算。

## 常见坑与经验
- `operator[]` 返回代理对象，不能把它当普通 `bool&` 保存。
- 位索引越界是逻辑错误，动态增长前先 `resize()`。

## 知识点覆盖
位集合、内存压缩、代理引用、掩码、统计。
