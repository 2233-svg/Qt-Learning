# QMargins
> Qt 6.11.1 · Qt Core · 来自 `QMargins`

## 作用定位
`QMargins` 用四个整数表示左、上、右、下边距，是矩形、布局与绘制区域常用的值类型。

## API 速查
| API | 是做什么的 |
|---|---|
| `left()` / `top()` / `right()` / `bottom()` | 读取各边边距。|
| `setLeft()` 等 | 修改单边边距。|
| `isNull()` | 判断四边是否全为零。|
| `operator+` / `operator-` | 组合或相减边距。|
| `operator*` / `operator/` | 按标量缩放。|

## 使用场景
计算内容区域、给矩形增加安全留白、将 UI 像素边距传入几何 API。

## 常见坑与经验
- 边距不是 `QRect`；应用到矩形时要明确是扩张还是收缩，以及左右/上下各自的符号。
- 整数缩放会截断；高 DPI 或动画插值需要更平滑结果时选择 `QMarginsF`。

## 知识点覆盖
边距、矩形几何、整数坐标、缩放、内容区域、高 DPI。
