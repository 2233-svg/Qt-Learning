# QHash::iterator
> Qt 6.11.1 · Qt Core · 来自 `QHash::iterator`

## 作用定位
`QHash::iterator` 是可写哈希迭代器，可遍历键值对并修改当前值。

## API 速查
| API | 是做什么的 |
|---|---|
| `key()` | 读取当前键。|
| `value()` | 读取或修改当前值。|
| `operator*()` | 访问当前值。|
| `operator++()` | 前进。|
| `erase()` | 通过容器删除当前位置并获取后继位置。|

## 使用场景
遍历缓存并更新命中信息，或按条件安全删除过期项。

## 常见坑与经验
- 需要删除当前项时使用 `erase(iterator)` 返回的后继迭代器，不能删除后再递增旧迭代器。
- 不要在迭代中调用可能 rehash 的插入或 reserve 操作。

## 知识点覆盖
可写迭代器、遍历删除、哈希重排、缓存清理、迭代器失效。
