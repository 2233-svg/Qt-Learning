# QMap
> Qt 6.11.1 · Qt Core · 来自 `QMap`

## 作用定位
`QMap<Key, T>` 是按键排序的关联容器，适合需要稳定有序遍历、范围查询或最小/最大键访问的映射数据。

## API 速查
| API | 是做什么的 |
|---|---|
| `insert()` / `emplace()` | 写入或替换键值。|
| `value()` | 读取键值或默认值。|
| `find()` / `lowerBound()` / `upperBound()` | 查找精确键或范围边界。|
| `firstKey()` / `lastKey()` | 读取最小或最大键。|
| `remove()` / `take()` | 删除键；`take()` 返回旧值。|
| `keys()` / `values()` | 返回有序键或值列表副本。|
| `keyValueBegin()` | 获取可结构化绑定遍历的范围入口。|

## 使用场景
按时间、排序 ID、版本号或区间边界保存记录，并需要有序导出或前后邻居查找。

## 常见坑与经验
- 相较 `QHash`，查找通常是对数复杂度；仅需快速精确查找且不需顺序时选择 `QHash`。
- 自定义 key 的 `<` 必须提供严格弱序关系，否则范围查询和排序都会出错。
- `value()` 的默认值会混淆“缺失”与“值恰好等于默认值”，需要时用 iterator。

## 知识点覆盖
有序映射、红黑树语义、范围查询、键排序、自定义比较、复杂度选择。
