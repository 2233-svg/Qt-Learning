# QHash
> Qt 6.11.1 · Qt Core · 来自 `QHash`

## 作用定位
`QHash<Key, T>` 是基于哈希表的关联容器，按键快速查找值。它不保证迭代顺序，适合索引、缓存和映射，不适合需要排序遍历的场景。

## API 速查
| API | 是做什么的 |
|---|---|
| `insert()` | 写入或替换键对应值。|
| `emplace()` | 原位构造值。|
| `value()` | 读取键值或默认值。|
| `find()` / `constFind()` | 返回键的迭代器。|
| `contains()` | 判断键存在。|
| `remove()` / `take()` | 删除键；`take()` 返回被移除值。|
| `reserve()` | 提前预留桶容量。|
| `keys()` / `values()` | 创建键或值列表副本。|

## 使用场景
用 ID 查对象、按路径缓存解析结果、按枚举或字符串索引配置。

## 常见坑与经验
- Qt 哈希迭代顺序不稳定，不能用于持久格式、用户展示排序或测试中的顺序断言。
- 自定义键需要定义匹配的 `qHash(key, seed)` 与相等关系；二者必须一致。
- 结构修改、rehash 或 detach 可能使迭代器失效，遍历删除时使用正确的 erase 模式。
- `value(key)` 返回默认构造值会掩盖“键不存在”，需要区分时先 `contains()` 或 `find()`。

## 知识点覆盖
哈希表、平均查找复杂度、自定义 hash、迭代顺序、迭代器失效、缓存。
