# QUtf8StringView
> Qt 6.11.1 · Qt Core · 来自 `QUtf8StringView`

## 作用定位
`QUtf8StringView` 是 UTF-8 字节文本的非拥有只读视图。它适合接收协议、JSON、日志和源代码中本来就是 UTF-8 的片段，避免先转成 `QString`。

## API 速查
| API | 是做什么的 |
|---|---|
| 构造函数 | 从 UTF-8 字节范围、字面量或兼容数组创建视图。 |
| `size()` | 查询字节长度。 |
| `data()` | 取得 UTF-8 首地址。 |
| `isEmpty()` | 判断空视图。 |
| `toString()` | 解码为 `QString`。 |
| 迭代接口 | 按底层代码单元遍历。 |

## 使用场景
高频解析 UTF-8 协议关键字时直接使用 view 比反复构造 `QString` 更轻。

## 常见坑与经验
- 它默认相信数据是 UTF-8；外部不可信字节仍要校验或用 decoder 处理错误。
- `size()` 是字节数，不是字符数。
- 和所有 view 一样，源缓冲区必须保持有效。
