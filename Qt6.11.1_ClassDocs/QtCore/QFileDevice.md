# QFileDevice
> Qt 6.11.1 · Qt Core · 来自 `QFileDevice`

## 作用定位
`QFileDevice` 是 `QFile`、`QTemporaryFile`、`QSaveFile` 等文件型设备的抽象基类，统一提供文件错误、权限、大小、位置和文件映射能力。

## API 速查
| API | 是做什么的 |
|---|---|
| `fileName()` | 返回关联路径。|
| `size()` | 查询文件长度。|
| `resize()` | 调整文件长度。|
| `permissions()` | 查询权限。|
| `setPermissions()` | 设置权限。|
| `map()` / `unmap()` | 映射文件区间到内存。|
| `error()` / `errorString()` | 查询文件设备错误。|
| `flush()` | 请求将写缓冲提交到底层设备。|

## 使用场景
需要通用处理不同文件设备，或将大型只读文件片段映射供随机访问解析时使用。

## 常见坑与经验
- `flush()` 不总等于数据已物理落盘；需要更强持久化保证时按平台与存储介质语义设计。
- 内存映射指针在 `unmap()`、关闭文件或修改文件后不可使用。
- 映射大文件并不会消除页错误和地址空间压力。

## 知识点覆盖
文件设备、内存映射、权限、缓冲刷新、持久化语义、错误诊断。
