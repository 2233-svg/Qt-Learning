# QFlags
> Qt 6.11.1 · Qt Core · 来自 `QFlags`

## 作用定位
`QFlags<Enum>` 将可组合的枚举位封装成类型安全值，避免用裸 `int` 表达一组开关。

## API 速查
| API | 是做什么的 |
|---|---|
| `testFlag()` | 判断某个枚举位是否设置。|
| `setFlag()` | 设置或清除一个枚举位。|
| `testAnyFlags()` | 判断是否命中任一给定位。|
| `testFlags()` | 判断是否包含全部给定位。|
| `operator|` / `operator&` | 组合或过滤位集合。|
| `toInt()` | 转为底层整数，仅用于互操作。|

## 使用场景
窗口选项、文件打开模式、网络能力、绘制特性等可独立组合的配置。

## 常见坑与经验
- 枚举项必须是单一位值；将复合值混入基础枚举会让 `testFlag()` 语义难以理解。
- 不要把无关 enum 的整数强转到 flags 类型，编译通过不代表语义正确。

## 知识点覆盖
位掩码、类型安全、枚举设计、组合选项、位运算。
