# QMultiMap::iterator
> Qt 6.11.1 · Qt Core · 来自 `QMultiMap::iterator`

## 作用定位
`QMultiMap::iterator` 是可写有序多值映射迭代器，可按键顺序遍历并修改当前关联值。

## API 速查
| API | 是做什么的 |
|---|---|
| `key()` | 读取当前键。|
| `value()` | 读取或修改当前值。|
| `operator++()` / `operator--()` | 前后移动。|
| `erase()` | 删除当前位置关联并返回后继位置。|

## 使用场景
按有序键批量修正关联值，或遍历删除过期的一对多记录。

## 常见坑与经验
- key 不能原地更改；要改变排序键，删除旧关联后插入新关联。
- 结构修改后以 `erase()` 返回的迭代器继续，避免使用失效位置。

## 知识点覆盖
有序多值映射、可写迭代、遍历删除、键排序、迭代器失效。
