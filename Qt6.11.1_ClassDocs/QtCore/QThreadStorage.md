# QThreadStorage
> Qt 6.11.1 · Qt Core · 来自 `QThreadStorage<T>`

## 作用定位
`QThreadStorage` 为每个线程保存一份独立数据，适合缓存不可共享的解析器、连接上下文或临时缓冲。
## API 速查
| API | 是做什么的 |
|---|---|
| `hasLocalData()` | 当前线程是否已有数据。 |
| `localData()` | 取得当前线程的数据引用，必要时创建。 |
| `setLocalData()` | 设置当前线程的数据。 |
## 使用场景
每个工作线程保留一个复用缓冲区，减少重复分配且避免共享锁。
## 常见坑与经验
- 数据按线程而不是任务划分；线程池复用线程时，旧任务留下的数据会被后续任务看到。
- 线程结束时才清理本地数据，不适合保存必须立即释放的稀缺资源。
- 不要用它传递跨线程结果。
## 知识点覆盖
线程本地存储、线程池复用、缓存、生命周期、共享状态替代方案。
