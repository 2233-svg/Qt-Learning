# Qt::totally_ordered_wrapper
> Qt 6.11.1 · Qt Core · 来自 `Qt::totally_ordered_wrapper<T>`
## 作用定位
`Qt::totally_ordered_wrapper` 为底层值提供全序包装，常用于让原本比较语义受限的值参与需要全序的泛型代码。
## API 速查
| API | 是做什么的 |
|---|---|
| 构造函数 | 包装一个值。 |
| 比较运算 | 提供可用于排序的全序关系。 |
| `value` 访问 | 取得被包装对象。 |
## 使用场景
需要把值放入排序容器或执行泛型比较，而原类型比较结果不完全满足要求。
## 常见坑与经验
- 全序包装是工程约定，不代表业务语义自然成立。
- 对浮点等类型使用时要清楚 NaN 的处理方式。
## 知识点覆盖
全序、泛型比较、排序容器、包装类型、比较语义。
