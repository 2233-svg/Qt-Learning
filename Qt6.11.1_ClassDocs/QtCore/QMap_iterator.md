# QMap::iterator
> Qt 6.11.1 · Qt Core · 来自 `QMap::iterator`

## 作用定位
`QMap::iterator` 是可写的有序映射迭代器，可按键升序遍历并修改当前键关联的值。

## API 速查
| API | 是做什么的 |
|---|---|
| `key()` | 读取当前键。|
| `value()` | 读取或修改当前值。|
| `operator*()` | 访问当前值。|
| `operator++()` / `operator--()` | 前后移动。|
| `erase()` | 删除当前位置并返回后继迭代器。|

## 使用场景
按时间或 ID 的稳定顺序修正数据，或安全清理满足条件的映射项。

## 常见坑与经验
- 键不可经迭代器修改；改变键等价于删除旧项再插入新项。
- 删除时采用 `it = map.erase(it)`，不要递增已经失效的迭代器。

## 知识点覆盖
有序映射、可写迭代、遍历删除、键不变量、迭代器失效。
