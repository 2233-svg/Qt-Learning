# QPointer
> Qt 6.11.1 · Qt Core · 来自 `QPointer`

## 作用定位
`QPointer<T>` 是指向 QObject 的受监测弱指针：对象销毁后它自动变为 `nullptr`，用于避免保留已删除 QObject 的裸指针。

## API 速查
| API | 是做什么的 |
|---|---|
| `data()` | 获取当前 QObject 指针或空。|
| `isNull()` | 判断对象是否已销毁或未设置。|
| `operator->()` | 访问仍存活对象成员。|
| `clear()` | 主动置空。|
| `swap()` | 交换两个守卫指针。|

## 使用场景
异步回调、缓存的 UI 对象引用、非所有者关系中需要检查 QObject 是否仍存活。

## 常见坑与经验
- 它不拥有对象，也不延长对象生命周期；需要延寿应使用父子关系或适当智能指针。
- “检查非空再调用”仍可能在多线程场景发生竞态，QObject 跨线程访问必须依赖线程模型与消息传递。
- 它只适用于 QObject 子类，普通 C++ 对象用 `std::weak_ptr` 等机制。

## 知识点覆盖
弱引用、QObject 销毁、异步回调、所有权、空悬指针、线程竞态。
