# QSharedMemory
> Qt 6.11.1 · Qt Core · 来自 `QSharedMemory`
## 作用定位
`QSharedMemory` 在进程间创建或附加一块共享内存。它只共享字节，不定义数据格式、生命周期协议或并发一致性。
## API 速查
| API | 是做什么的 |
|---|---|
| `setKey()` | 指定跨进程标识。 |
| `create(size)` | 创建并附加新段。 |
| `attach()` / `detach()` | 连接或断开已有段。 |
| `data()` / `constData()` | 访问共享字节。 |
| `lock()` / `unlock()` | 协调使用同一段的进程。 |
| `error()` / `errorString()` | 获取创建、附加和锁失败原因。 |
## 使用场景
一个进程写入固定头部加 payload，另一个进程先锁定、校验版本和长度后读取。
## 常见坑与经验
- 不要存裸指针、Qt 对象或依赖本进程地址的结构。
- 共享段崩溃残留、权限和版本不兼容都要在协议层处理。
- lock 不能取代原子内存序或完整的读写协议设计。
