# QLine
> Qt 6.11.1 · Qt Core · 来自 `QLine`

## 作用定位
`QLine` 是由两个整数 `QPoint` 构成的二维线段值类型，适合像素网格、整数几何和离散布局计算。

## API 速查
| API | 是做什么的 |
|---|---|
| `p1()` / `p2()` | 读取两个端点。|
| `setP1()` / `setP2()` | 修改端点。|
| `x1()` / `y1()` / `x2()` / `y2()` | 读取端点坐标。|
| `dx()` / `dy()` | 读取横纵增量。|
| `center()` | 返回整数中心点。|
| `translated()` / `translate()` | 返回平移副本或原地平移。|
| `isNull()` | 判断两端点是否相同。|

## 使用场景
像素对齐的绘制、网格连线、整数区域边界和 `QPainter` 线段参数。

## 常见坑与经验
- `center()` 在奇数距离上进行整数截断；需要精确几何中心应使用 `QLineF`。
- 它是有限线段，不表示无限直线；相交和距离等浮点几何需求选择 `QLineF`。

## 知识点覆盖
整数几何、线段、像素对齐、坐标差、平移、精度选择。
