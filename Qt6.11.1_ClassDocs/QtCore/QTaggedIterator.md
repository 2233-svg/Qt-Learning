# QTaggedIterator
> Qt 6.11.1 · Qt Core · 来自 `QTaggedIterator`

## 作用定位
`QTaggedIterator` 给底层迭代器附加类别标签，让 Qt 容器或适配器在保持 ABI/类型约束的同时表达迭代能力。
## API 速查
| API | 是做什么的 |
|---|---|
| 构造函数 | 包装一个底层迭代器。 |
| `operator*` / `operator->` | 访问当前位置。 |
| `++ -- + -` | 按标签支持相应移动操作。 |
| 比较运算 | 判断两个迭代器位置关系。 |
## 使用场景
主要出现在 Qt 内部和高级泛型代码中，普通应用很少直接写它。
## 常见坑与经验
- 标签不让一个弱迭代器 magically 支持随机访问；底层能力必须真实存在。
- 修改容器后的失效规则仍由底层迭代器决定。
## 知识点覆盖
迭代器类别、泛型适配、STL 兼容、失效规则。
