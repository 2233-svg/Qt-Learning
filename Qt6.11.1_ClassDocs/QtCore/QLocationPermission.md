# QLocationPermission
> Qt 6.11.1 · Qt Core · 来自 `QLocationPermission`

## 作用定位
`QLocationPermission` 描述移动与桌面平台访问位置服务的运行时权限，可区分精确/近似位置以及前台/后台使用范围。

## API 速查
| API | 是做什么的 |
|---|---|
| `setAccuracy()` | 请求精确或近似位置精度。|
| `setAvailability()` | 请求前台或后台可用范围。|
| `accuracy()` | 查询要求的精度。|
| `availability()` | 查询使用范围。|
| `checkPermission()` | 查询当前授权状态。|
| `requestPermission()` | 异步请求系统授权。|

## 使用场景
地图定位、附近设备、运动轨迹或基于地区的功能，在用户实际触发后按最小权限请求。

## 常见坑与经验
- 精确位置和后台位置应只在确有必要时申请，系统与商店审核对其限制更严格。
- 获得权限不等于立刻有定位结果，仍需处理定位服务关闭、无信号和平台精度限制。
- 不要把位置历史默认上传或长期保存，需有明确产品和隐私策略。
