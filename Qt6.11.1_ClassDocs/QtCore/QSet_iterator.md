# QSet::iterator
> Qt 6.11.1 · Qt Core · 来自 `QSet<T>::iterator`
## 作用定位
`QSet::iterator` 是可变迭代位置接口，但集合元素本身不能原地修改，因为改变哈希值会破坏桶结构。
## API 速查
| API | 是做什么的 |
|---|---|
| `operator*` | 访问当前元素位置。 |
| `++` / `--` | 移动迭代器。 |
| `erase()` | 通过容器删除当前位置元素并取得下一个位置。 |
## 使用场景
筛除元素时按 Qt 容器的 erase 约定安全前进。
## 常见坑与经验
- 需要“改元素”时应删除旧值后插入新值。
- 插入、清空或 rehash 后旧 iterator 不可再用。
## 知识点覆盖
哈希不变量、元素唯一性、迭代删除、失效规则。
