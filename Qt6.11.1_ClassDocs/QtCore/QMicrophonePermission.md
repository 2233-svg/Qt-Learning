# QMicrophonePermission
> Qt 6.11.1 · Qt Core · 来自 `QMicrophonePermission`

## 作用定位
`QMicrophonePermission` 表示应用录制或访问麦克风输入所需的运行时权限。

## API 速查
| API | 是做什么的 |
|---|---|
| `checkPermission()` | 查询当前麦克风授权状态。|
| `requestPermission()` | 异步请求系统授权。|

## 使用场景
语音输入、录音、通话、音频分析功能在用户主动启动时申请权限。

## 常见坑与经验
- 系统声明文本与权限申请时机应清晰说明录音目的，避免在无上下文时弹窗。
- 获权不代表音频输入必然可用，仍需处理无设备、被其他应用独占和平台静音策略。
- 未经用户明确同意，不应录制、上传或持久化环境音频。

## 知识点覆盖
麦克风权限、录音隐私、运行时授权、设备可用性、最小权限。
