# QEasingCurve
> Qt 6.11.1 · Qt Core · 来自 `QEasingCurve`

## 作用定位
`QEasingCurve` 将动画的线性进度 `0..1` 映射为非线性进度，决定对象是匀速、先慢后快、回弹还是弹性过渡。

## API 速查
| API | 是做什么的 |
|---|---|
| `setType()` | 选择内置缓动类型。|
| `valueForProgress()` | 根据线性进度计算缓动后进度。|
| `setAmplitude()` | 调整弹性、回弹类曲线幅度。|
| `setPeriod()` | 调整弹性周期。|
| `setOvershoot()` | 调整 Back 类曲线越界程度。|
| `addCubicBezierSegment()` | 组成自定义三次贝塞尔曲线。|
| `setCustomType()` | 使用自定义函数。|

## 使用场景
为 `QPropertyAnimation` 设置更符合交互直觉的进入、退出、按钮反馈与列表展开效果。

## 常见坑与经验
- 视觉缓动不能掩盖状态延迟；网络或业务完成仍应由真实异步信号驱动。
- 弹性/回弹曲线可能超过 `0..1`，用于不允许越界的数值属性时需谨慎。
- 自定义函数应连续且足够快，避免每帧分配或访问 UI 外部状态。

## 知识点覆盖
插值、动画曲线、贝塞尔、回弹、越界、交互设计、帧性能。
