# QEvent
> Qt 6.11.1 · Qt Core · 来自 `QEvent`

## 作用定位
`QEvent` 是 Qt 事件系统的基类。窗口、输入、定时器、语言切换、动态属性和自定义通知最终都以事件对象投递给 `QObject::event()`。

## API 速查
| API | 是做什么的 |
|---|---|
| `type()` | 返回事件类型枚举。|
| `accept()` / `ignore()` | 标记事件是否被接受。|
| `isAccepted()` | 查询接受状态。|
| `spontaneous()` | 判断是否来自系统而非应用发送。|
| `registerEventType()` | 注册用户自定义事件类型。|
| `clone()` | 复制可克隆事件。|

## 使用场景
自定义跨对象通知可定义 `QEvent` 子类并通过 `postEvent()` 异步投递；普通对象通信优先使用信号槽。

## 常见坑与经验
- `sendEvent()` 同步调用，可能立即重入接收对象；跨线程或延后执行用 `postEvent()`。
- 接受状态是否影响后续分发由具体事件类别决定，不能把 `accept()` 当作通用“停止传播”。
- 自定义类型应通过 `registerEventType()` 获取，避免与 Qt 或其他库冲突。

## 知识点覆盖
事件系统、同步与异步投递、接受状态、自定义事件、重入、线程通信。
