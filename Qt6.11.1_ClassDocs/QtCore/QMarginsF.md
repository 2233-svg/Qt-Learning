# QMarginsF
> Qt 6.11.1 · Qt Core · 来自 `QMarginsF`

## 作用定位
`QMarginsF` 以 `qreal` 保存四边边距，适合缩放、动画、矢量绘制和高 DPI 布局中的非整数几何。

## API 速查
| API | 是做什么的 |
|---|---|
| `left()` / `top()` / `right()` / `bottom()` | 读取浮点边距。|
| `setLeft()` 等 | 修改一侧边距。|
| `toMargins()` | 转换为整数边距，可能发生舍入。|
| `isNull()` | 判断四边是否均为零。|
| `operator+` / `operator-` | 组合边距。|
| `operator*` / `operator/` | 按比例缩放。|

## 使用场景
对 `QRectF` 扩缩、过渡动画、打印/矢量布局以及与逻辑像素比例协作。

## 常见坑与经验
- 多次浮点累积会带来误差，最终像素对齐时应统一取整策略。
- 转为 `QMargins` 的每一边舍入方式会影响总尺寸，不能分别随意截断再做布局。

## 知识点覆盖
浮点几何、边距、缩放、舍入、高 DPI、布局精度。
