# QPointF
> Qt 6.11.1 · Qt Core · 来自 `QPointF`

## 作用定位
`QPointF` 是浮点二维坐标和向量，适用于绘图、动画、缩放变换和高 DPI 布局。
## API 速查
| API | 是做什么的 |
|---|---|
| `(x, y)` / `setX/setY` | 创建或修改浮点坐标。 |
| `x/y` | 读取分量。 |
| `manhattanLength()` | 计算曼哈顿距离。 |
| `toPoint()` | 四舍五入到整数像素。 |
| `dotProduct()` | 计算两个二维向量点积。 |
| `+ - * /` | 平移或标量缩放。 |
## 使用场景
用 `QPointF` 保存变换后的场景坐标，绘制前按需要转换到目标设备坐标。
## 常见坑与经验
- 浮点结果不用 `==` 判断几何相等，应使用容差。
- `toPoint()` 会舍入；若需要向下/向上取整，应分别处理分量。
- 不能把屏幕坐标与场景坐标直接相减，先完成坐标变换。
## 知识点覆盖
浮点精度、向量点积、坐标变换、高 DPI、舍入。
