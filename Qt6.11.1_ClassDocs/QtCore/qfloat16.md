# qfloat16
> Qt 6.11.1 · Qt Core · 来自 `qfloat16`

## 作用定位
`qfloat16` 是 IEEE 754 半精度浮点值类型，用更小存储换取有限精度和范围，常用于图形、机器学习张量和大规模数值缓存。

## API 速查
| API | 是做什么的 |
|---|---|
| 构造函数 `qfloat16(float)` | 从单精度转换为半精度。|
| `operator float()` | 转回单精度参与计算。|
| 算术运算符 | 执行半精度相关运算或转换后运算。|
| `qFloatToFloat16()` | 批量从 float 转 half。|
| `qFloatFromFloat16()` | 批量从 half 转 float。|

## 使用场景
存储 GPU 交换数据、图像通道、模型权重或对精度要求不高的大数组。

## 常见坑与经验
- 半精度的有效数字和动态范围远小于 `float`；累计求和、金融计算、坐标高精度计算不适合直接使用。
- 转换会产生舍入、溢出或非正规数行为，必须以实际数据范围测试。
- 磁盘/网络格式还要明确字节序与版本，不能只写 `sizeof(qfloat16)`。
