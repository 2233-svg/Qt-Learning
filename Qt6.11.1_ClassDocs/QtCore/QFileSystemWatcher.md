# QFileSystemWatcher
> Qt 6.11.1 · Qt Core · 来自 `QFileSystemWatcher`

## 作用定位
`QFileSystemWatcher` 监控指定文件或目录路径的变化，并通过信号通知内容、元数据或目录条目发生变化。

## API 速查
| API | 是做什么的 |
|---|---|
| `addPath()` / `addPaths()` | 开始监控一个或多个路径。|
| `removePath()` / `removePaths()` | 停止监控路径。|
| `files()` / `directories()` | 查询当前监控集合。|
| `fileChanged()` | 文件发生变化或被删除时通知。|
| `directoryChanged()` | 目录条目发生变化时通知。|

## 使用场景
配置热加载、编辑器文件树刷新、开发工具自动重建、日志目录监控。

## 常见坑与经验
- 信号表示“可能发生变化”，不是提供完整增量；收到后重新检查实际文件状态。
- 原子保存常以“写临时文件再 rename”完成，原路径监控可能失效或需要重新 `addPath()`。
- 高频写入可能合并为少量通知；不要假设每次写入都对应一个信号。
- 监控数量和可用性受平台限制，关键可靠同步不能只依赖 watcher。

## 知识点覆盖
文件监控、信号合并、原子替换、路径重注册、跨平台限制、热加载。
