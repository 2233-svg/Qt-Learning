# QList
> Qt 6.11.1 · Qt Core · 来自 `QList`

## 作用定位
`QList<T>` 是 Qt 的通用顺序容器。Qt 6 中它采用连续存储策略，适合大多数按索引访问、追加和遍历的值序列。

## API 速查
| API | 是做什么的 |
|---|---|
| `append()` / `prepend()` | 在尾部或头部添加元素。|
| `insert()` | 在指定位置插入。|
| `removeAt()` / `takeAt()` | 删除元素；`takeAt()` 返回被删除值。|
| `at()` / `operator[]` | 按索引读取或访问元素。|
| `first()` / `last()` | 读取两端元素。|
| `contains()` / `indexOf()` | 查找元素。|
| `reserve()` | 预留容量，降低追加时重分配。|
| `sliced()` | 获取子列表副本。|

## 使用场景
保存任务、记录、模型行数据、解析后的字段或 UI 项目等顺序集合。

## 常见坑与经验
- 中间插入/删除需要移动后续元素，频繁操作时考虑不同数据结构或批量重建。
- 对容器的结构修改可能使指针、引用和迭代器失效；不要跨 `append()`/`insert()` 保存它们。
- `operator[]` 不做越界检查，外部索引先验证范围。

## 知识点覆盖
顺序容器、连续存储、容量、迭代器失效、索引访问、算法复杂度。
