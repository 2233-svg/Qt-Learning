# QException
> Qt 6.11.1 · Qt Core · 来自 `QException`

## 作用定位
`QException` 是可跨 `QtConcurrent`/任务框架边界传递的异常基类。它允许任务系统复制并在等待结果处重新抛出异常。

## API 速查
| API | 是做什么的 |
|---|---|
| `raise()` | 重新抛出当前异常。|
| `clone()` | 复制当前异常对象。|

## 使用场景
自定义任务异常类型继承它，在后台计算检测到不可恢复错误时抛出，并由 `QFuture::result()` 等等待点处理。

## 常见坑与经验
- 异常类型必须能正确 `clone()`，否则跨线程任务边界无法保留具体错误。
- 不能让异常越过 C 回调或 Qt 元对象边界而无人捕获；异步 API 也应提供错误信号或结果对象。

## 知识点覆盖
异常、跨线程任务、异常复制、错误传播、C++ 边界。
