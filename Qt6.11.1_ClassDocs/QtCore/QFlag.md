# QFlag
> Qt 6.11.1 · Qt Core · 来自 `QFlag`

## 作用定位
`QFlag` 是 Qt 用于桥接枚举位标志与 `QFlags` 运算的轻量辅助类型，普通业务代码很少需要直接声明它。

## API 速查
| API | 是做什么的 |
|---|---|
| 构造函数 | 从整型/枚举位值构造辅助对象。|
| 整数转换 | 支持与位运算表达式兼容。|

## 使用场景
阅读 Qt 定义的 `operator|`、`operator&` 模板或调试 flags 表达式时可能遇到。

## 常见坑与经验
- 应用层应使用实际枚举和 `QFlags<Enum>` 别名，不要用 `QFlag` 作为业务字段类型。

## 知识点覆盖
位标志、枚举、运算符桥接、类型安全、Qt 模板辅助。
