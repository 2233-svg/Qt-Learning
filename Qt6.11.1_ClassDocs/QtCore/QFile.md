# QFile
> Qt 6.11.1 · Qt Core · 来自 `QFile`

## 作用定位
`QFile` 是文件路径上的 `QIODevice` 实现，支持读取、写入、重命名、复制、链接和权限查询。

## API 速查
| API | 是做什么的 |
|---|---|
| `setFileName()` | 设置目标文件路径。|
| `open()` / `close()` | 打开或关闭文件设备。|
| `readAll()` / `write()` | 读取或写入字节。|
| `exists()` | 判断路径是否存在。|
| `copy()` / `rename()` | 复制或移动/改名。|
| `remove()` | 删除文件。|
| `link()` | 创建链接。|
| `permissions()` / `setPermissions()` | 查询或设置权限位。|

## 使用场景
读取配置、写入导出数据、流式处理文件、执行安全的临时文件替换流程。

## 常见坑与经验
- `open()` 失败后检查 `errorString()`；权限、路径编码、占用和目录不存在都会失败。
- `readAll()` 不适合大文件，改用分块 `read()`。
- 路径检查与打开之间可能被其他进程替换；安全敏感操作应尽可能尽快打开并基于已打开句柄处理。
- 覆盖写入关键文件优先采用 `QSaveFile`，避免崩溃留下半个文件。
