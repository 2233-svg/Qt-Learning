# QNativeIpcKey
> Qt 6.11.1 · Qt Core · 来自 `QNativeIpcKey`

## 作用定位
`QNativeIpcKey` 描述供本机进程间通信资源使用的原生键名与类型，用于共享内存、系统信号量等跨进程对象的稳定命名。

## API 速查
| API | 是做什么的 |
|---|---|
| `setNativeKey()` | 设置平台原生 IPC 标识。|
| `nativeKey()` | 读取实际原生键。|
| `setType()` | 指定 IPC 资源类型。|
| `type()` | 查询资源类型。|
| `isEmpty()` | 判断是否未设置键。|
| `legacyKey()` | 获取兼容旧式键表示。|

## 使用场景
为 `QSharedMemory`、`QSystemSemaphore` 等跨进程资源构造可在同一用户或会话范围内稳定识别的键。

## 常见坑与经验
- IPC 键是命名约定，不是访问控制；其他进程若知道键仍可能尝试连接，需依赖平台权限和协议认证。
- 键的命名空间、用户隔离和应用版本策略应统一，避免不同程序/测试环境冲突。
- 平台原生键规则不同，不能假设某个文件路径式字符串在所有系统都等价。

## 知识点覆盖
本地 IPC、共享内存、命名空间、平台差异、资源命名、安全边界。
