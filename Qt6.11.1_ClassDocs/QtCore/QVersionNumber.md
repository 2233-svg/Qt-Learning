# QVersionNumber
> Qt 6.11.1 · Qt Core · 来自 `QVersionNumber`
## 作用定位
`QVersionNumber` 保存由多个整数段组成的版本号，并按版本语义比较，例如 `1.10` 大于 `1.2`。
## API 速查
| API | 是做什么的 |
|---|---|
| 构造函数 | 从整数段创建版本。 |
| `fromString()` / `toString()` | 解析和格式化。 |
| `segments()` / `segmentAt()` | 读取版本段。 |
| `normalized()` | 去除尾部无意义零段。 |
| `compare()` | 按段比较版本先后。 |
| `isNull()` | 判断无版本段。 |
## 使用场景
插件 ABI、配置迁移、文件格式版本判断。
## 常见坑与经验
- 它只处理数字段，不表达 `alpha`、`rc1` 等预发布语义。
- 字符串比较版本号会错，使用 `compare()`。
- 归一化会影响尾部 0 的显示，不要丢掉业务需要的格式。
## 知识点覆盖
版本比较、数字段、配置迁移、语义版本边界、字符串解析。
