# QLEInteger
> Qt 6.11.1 · Qt Core · 来自 `QLEInteger`

## 作用定位
`QLEInteger<T>` 将整数以小端字节序存储，适合直接表示协议或文件格式中的 little-endian 固定宽度字段。

## API 速查
| API | 是做什么的 |
|---|---|
| 构造/赋值 | 从本机整数写入小端存储。|
| 转换运算符 | 读取为本机字节序整数。|
| `qToLittleEndian()` | 将整数或数组转换为小端字节序。|
| `qFromLittleEndian()` | 将小端字节序转换为本机值。|

## 使用场景
解析 Windows/RIFF 等小端文件格式、定义设备协议的固定字段。

## 常见坑与经验
- 它只处理字节序；结构体填充、对齐、大小与版本仍需显式设计。
- 不要把从网络来的任意字节 `reinterpret_cast` 成 C++ 结构体，应逐字段验证长度后转换。

## 知识点覆盖
小端序、二进制协议、文件格式、对齐、跨平台、输入验证。
