# QLineF
> Qt 6.11.1 · Qt Core · 来自 `QLineF`

## 作用定位
`QLineF` 是由两个 `QPointF` 构成的浮点线段，提供长度、角度、单位向量、交点与投影等二维几何计算。

## API 速查
| API | 是做什么的 |
|---|---|
| `length()` | 返回线段长度。|
| `angle()` / `angleTo()` | 计算与 X 轴或另一线段的角度。|
| `unitVector()` | 返回同方向单位线段。|
| `normalVector()` | 返回法向量线段。|
| `pointAt(t)` | 按参数取得线上点。|
| `intersects()` | 计算两线段/直线的交点关系。|
| `setLength()` | 保持起点和方向改变长度。|
| `fromPolar()` | 由长度和角度构造。|

## 使用场景
拖拽方向、命中测试、图形编辑器辅助线、物理或可视化中的 2D 向量计算。

## 常见坑与经验
- 浮点几何不应用 `==` 判断相等；使用适合坐标尺度的容差。
- `intersects()` 需要区分无交点、边界相交和无限线交点的结果类型。
- 角度单位是度，和常见数学库的弧度 API 交互时需显式转换。

## 知识点覆盖
浮点几何、线段相交、向量、角度、容差、参数方程、坐标系。
