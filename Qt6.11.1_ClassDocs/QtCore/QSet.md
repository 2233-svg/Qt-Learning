# QSet
> Qt 6.11.1 · Qt Core · 来自 `QSet<T>`

## 作用定位
`QSet<T>` 是基于哈希的无序唯一元素集合，适合成员资格判断、去重和集合运算。
## API 速查
| API | 是做什么的 |
|---|---|
| `insert()` | 插入元素；已有相等元素不重复增加。 |
| `contains()` | 平均常数时间判断成员资格。 |
| `remove()` | 删除指定值并返回删除数。 |
| `unite/intersect/subtract` | 做并集、交集、差集。 |
| `values()` | 转为列表；不保证顺序。 |
| `reserve()` | 批量插入前预留哈希桶容量。 |
## 使用场景
```cpp
QSet<QString> seen;
if (!seen.contains(id))
    seen.insert(id);
```
## 常见坑与经验
- 遍历顺序不稳定，展示或持久化前显式排序。
- 自定义类型必须提供正确的 `qHash` 和相等比较；两者语义必须一致。
- 插入/删除可能使迭代器失效，不要跨修改保存。
## 知识点覆盖
哈希、去重、集合运算、自定义 `qHash`、复杂度、无序性。
