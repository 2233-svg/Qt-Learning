# QPauseAnimation
> Qt 6.11.1 · Qt Core · 来自 `QPauseAnimation`

## 作用定位
`QPauseAnimation` 是只消耗时间、不改变属性值的动画项，常嵌入顺序动画组以形成停顿节奏。

## API 速查
| API | 是做什么的 |
|---|---|
| 构造函数 `(duration)` | 创建指定时长的暂停。|
| `setDuration()` | 设置暂停毫秒数。|
| `duration()` | 查询暂停长度。|
| `start()` | 独立运行或由动画组驱动。|

## 使用场景
提示出现后停留一段时间再淡出，或在多步教程、加载动效中插入明确的视觉间隔。

## 常见坑与经验
- 它只暂停动画时间线，不会阻塞线程或等待异步网络/IO 完成。
- 必须等待真实业务结果时，使用状态机、信号槽或 future continuation，而不是猜测固定暂停时长。

## 知识点覆盖
动画停顿、顺序动画、时间线、非阻塞、异步状态、交互节奏。
